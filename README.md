# ACES Redesign — CodeFest 2026 UI/UX Challenge

A mobile-first redesign of [acesknust.com](https://www.acesknust.com), the website of the
Association of Computer Engineering Students at KNUST.

Three deliverables, all interactive:

| | What it is |
|---|---|
| **Home** | The redesigned website — 18 sections covering all nine pages, responsive from 375px to desktop |
| **Prototype** | The same product as a mobile app: bottom tab bar, cart, checkout, filters, lightbox, dark mode |
| **Case study** | The argument — eight findings from the live site, the IA rework, the design system, and a rubric map |

## Running it locally

```bash
npm start
```

Then open <http://localhost:8123>.

## How this repo is laid out

- `design-source/` — the original Claude Design files (`.dc.html`). **Source of truth.** Edit these.
- `site/` — the deployable static site, generated by `npm run build`. Don't hand-edit.
- `build.js` — turns `design-source/` into `site/`.

The `.dc.html` format is a small template language (`sc-if`, `sc-for`, `{{ }}`) compiled to React
at runtime by `support.js`. The build step injects React and rewrites paths so the pages run as
plain static HTML in any browser — no framework, no server.

## Checks

```bash
npm run check
```

Verifies every referenced asset exists, every page renders, and no template placeholders leak
into the output.
